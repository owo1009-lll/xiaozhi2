# M4 OMR 识别需求与验收规范

> 状态:2026-07-16 冻结。M4 仍为 eval-only，`studentGateReady=false`。未通过本规范的识别谱不得进入学生诊断层。

## 1. 基线与目标

冻结的 5 份真实照片独立 gold 基线:

- 音高 precision=`84.7%`，recall=`71.5%`;
- 绝对四分音符起点准确率=`2.2%`;
- 小节结构准确率=`43.8%`;
- 完整严格通过=`0/5`。

以上节奏数字受记谱版本和时值尺度差异影响，不能单独解释为 OMR 全部读错；但严格通过 `0/5` 足以证明当前输出不能自动采纳。

## 2. 通用安全原则

1. `100%` 表示学生端的**放行要求**，不是声称模型能永久达到 100%。证据不足时必须拒绝整行、整页或对应小节。
2. OMR 单方证据不得直接指责学生。未人工核谱时，`missing` / `extra` 和节奏硬判必须关闭。
3. 后处理不得为了“凑满拍数”无证据地发明休止符、改音高或改时值。
4. 调参、训练和候选选择只使用 train/validation；5 份冻结照片 gold 只用于最终比较。
5. 技法记号只选择音准评判模式，不降低音准标准。

## 3. P0 音高链

| 对象 | 学生端放行要求 | 失败处置 |
|---|---:|---|
| 谱号，含换行重申 | 可验证正确 | 整行拒绝 |
| 调号 | 可验证正确 | 调号影响范围全部拒绝 |
| 临时升降号与还原号 | precision `>=99%` | 低置信音符转复核 |
| 符头位置与加线 | precision `>=99%` | 低置信音符转复核 |
| 音符顺序 | 已放行片段不得错序 | 片段拒绝 |
| 小节归属 | 已放行片段不得跨节错归 | 小节拒绝 |
| 符头坐标 | 中心偏差 `<=0.5` 个中位符头宽度 | 禁止绘制学生红框 |

补充指标:

- 音高必须使用谱号、调号、临时记号解析后的 sounding/written pitch 统一口径；
- 单独报加线音、临时记号音、换行后首音的 P/R；
- 坐标准确率与音高 P/R 分开报告，不得用“有 bbox”代替“bbox 准”。

## 4. P1 节奏与结构链

必须识别:

- 拍号;
- 符头实/空、符干、符杠/符尾、附点、延音线;
- 各类休止符;
- 小节线;
- 弱起小节;
- 反复线、一/二房子、D.C./D.S./Coda 等路线记号。

### 4.1 受限小节修复

小节时值约束只能在**已观测候选**中选择:

1. 前提是拍号可信(`meterKnown=true`);
2. 候选只来自 OMR top-k、可见符尾/符杠/附点/休止符证据;
3. 以最小编辑代价求解，并保留原始草稿、候选和修复理由;
4. 弱起、收尾不完全小节、跨小节延音、复调声部必须单独建模;
5. 没有唯一高置信解时输出 `review_required`，不得自动改谱。

开发顺序为:候选包含率 oracle -> 不看 gold 的选择器 -> 独立照片复验。oracle 不达标时，禁止直接调选择器。

### 4.2 反复路线

“检出反复记号”不等于“正确展开演奏顺序”。自动展开必须同时处理房子、嵌套反复、D.C./D.S./Coda，并由音频路线证据确认。在有独立 gold 和音频路线验收前，只输出 `repeat-route-review-required`。

## 5. P2 记号与技法模式

需保留读取:

- 连线/连奏区;
- `tr`、波音和装饰小音符;
- 一干多头(双音);
- 泛音记号;
- 指法 `0`、`pizz.` / `arco`。

技法感知音准的触发原则是:

`score_mark_detected OR audio_pattern_detected`

原因是揉弦和滑音常未明写在谱上。任一路证据不足时都可以进入技法感知评判，但最终音准结论仍要过原有 precision 闸门。谱面记号的“已有读取路径”不等于“已经独立 gold 验收”。

## 6. P3 当前不做

- 速度记号，除非产品日后增加“演奏过快/过慢”反馈;
- 力度、表情文字、标题和页码。

P3 不进入当前准确率和工时预算。

## 7. 实施优先级

代码实验与学生端放行顺序不同:

1. **安全闸门先行:**谱号/调号/拍号缺失或冲突必须 fail-closed;
2. **P1 后处理先实验:**它不改 OMR 引擎，且当前最弱，先跑候选 oracle 可以快速判断有无上限;
3. **P0 准确率加固:**临时记号、加线音、换行谱号分层评测;
4. **反复路线:**先检出、再展开、最后用音频确认;
5. **P2 保持现有路径:**待独立记号 gold 到位再优化。

## 8. 公开谱面训练的已验证边界

DoReMi v1 有图像、页级 OMR 注释和 MusicXML，适合做 Stage-B 监督适配实验。2026-07-16 的低负载 pilot 按作品隔离 train/validation/test=`96/48/48` 个谱表对，32-step DoRA 在 held-out 数字谱上提高 token accuracy，但在冻结 5 份真照片上:

- Clarity 官方基线:P/R=`72.77%/35.53%`，onset/measure=`2.81%/10.10%`;
- DoReMi 适配候选:P/R=`75.94%/36.10%`，onset/measure=`5.18%/6.65%`;
- 完整严格通过仍为 `0/5`，measure 退化 `-3.45` 个百分点。

因此候选按预声明的四指标不退化规则 `reject-and-delete`。结论是:公网配对谱面可改善数字谱域特征，但**仅追加干净数字谱不能修复真实照片的节奏/小节结构**。后续数据必须包含拍照域退化、休止/符杠/附点标注和小节结构监督，否则不再启动重训练。

## 9. 是否需要录音

- **OMR 引擎优化不需要录音:**需要图片/PDF + 独立 MusicXML/MEI gold。
- **OMR 与演奏诊断的双证放行需要录音:**录音只用于验证 OMR 候选与实际演奏是否一致，不应被当成 OMR gold。
- **P1 音频反哺必须后置:**先证明 OMR 候选中包含正确节奏，再评估音频是否能在不看 gold 时选对，避免循环证明。

## 10. 2026-07-16 P0/P1/专项 gold 实施结果

- P0 fail-closed 已接入照片谱诊断管线。每项结构允许“显式符号证据 **或** 可审计结构佐证”：无调号且 MusicXML 为零/默认零可证明 C 大调或 a 小调；行首谱号全覆盖、语义一致、导出为 G2 且音域合理可佐证谱号；导出拍号且可比小节总时值一致率 `>=90%` 可佐证拍号。任何原始/导出冲突仍优先拒绝。
- 修正 fail-impossible 后，又修复了 Audiveris raw XML 中“带 `fifths` 但无 `shape`”调号以及 `time-whole` 拍号的解析。冻结 5 张真实照片中 P0 完整通过为 `1/5`，分项为谱号 `3/5`、调号 `2/5`、拍号 `2/5`。剩余失败是实际证据不足或冲突，不再包含“C 大调因为没有符号而必失败”或 raw 节点漏解析造成的假失败。
- 12 份缓存三变体反馈回放显示：旧路径 `10 full + 1 degraded + 1 retake`，严格 P0 后 `11 review + 1 retake`。绿色降级模拟可保留 11 份、870 个音频确认音且不输出指控；但既有独立 gold 审计的双证总体 precision=`98.58%`、最差单曲=`80%`，未过逐曲门槛，因此绿色降级仍为 eval-only，生产保持全 review。
- P1 有界视觉候选已增加符杠相邻时值类与小节内反复连音组传播：gold-meter oracle 从 `44/50=88%` 提高到 `49/50=98%`，候选生成门槛已过。但真实 top-k 保留率对截断很敏感：`k=16/32` 只有 `30/50=60%`，`k=512` 才达 `48/50=96%`。扩大后 Basic Pitch 只有 `14/50` 小节具备足够 IOI 证据，多个候选对已检出的少数间隔得分完全相同；固定 margin 选择 `0/50`，按曲留一也选择 `0/50`。连续 pYIN F0 持续形状对照也只有 `11/50` 小节证据就绪，固定 margin 和按曲留一同样均选择 `0/50`。另有 `33/50` 小节仅是整体记谱尺度缩放，在未知速度下音频相对 IOI 无法区分拍号；拍号必须由 P0 独立证据确定。因此 `selectorTrainingAllowed=true` 仅表示可以研究选择器，`runtimeReady=false`，不得自动改谱。
- 自适应谱线间距缩放已用新增的《北京的金山上》人工 MusicXML 做独立 gold 盲测：现有 `up2` 的 pitch P/R/F1=`87.14%/35.47%/50.41%`，修正实验对比度链后的自适应缩放为 `28.28%/16.28%/20.66%`。自适应变体虽输出更多音符，但独立 gold 三项都退化，故保持 eval-only，不接生产。
- 已建立临时记号 `226` 个、加线音 `453` 个、换行谱号 `46` 行的专项 gold；换行谱号当前正确 `43/46`。坐标任务生成 `1937` 条，但独立人工 bbox 尚未完成，故 `coordinateGoldReady=false`，不得用模型自身 bbox 计算坐标准确率。
- 反复线、房子、D.C./D.S./Coda/Fine 已统一保留为路线结构证据；任何非平凡路线当前均输出 `repeat-route-review-required`，不自动展开演奏顺序。
- P2 不增加训练或优化预算。
