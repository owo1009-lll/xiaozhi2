Round 5 定向诊断录制与真值包

这 12 条录音槽位正好覆盖冻结合同的最低分母：每类 12 个真实错误、24 个混淆负例，其中 fresh-blind 各保留 6/12；同时覆盖 2 名演奏者、3 台设备和 2 个房间。

盲测红线：先下载并登记新曲目和位置，再录音。calibration 与 fresh-blind 不得复用曲目，也不得复用同一个演奏者-设备-房间组合。模板中的 replace-* 曲目 ID 必须替换。任何新包结果都不得用于回调已经冻结的阈值。
安全边界：下载或完成本包不会开启自动判分。每条录音只有在逐音复核全部演奏错误后，才可把 completeErrorInventory 从 false 改成 true。

完成顺序

  1. 为 12 个槽位各选一份此前未进入 Round4/调参的单声部 MusicXML；两个 split 的曲目完全分开。
  2. 每条录音在 4 个不同谱音位置分别制造 wrong/missing/extra/drag，并另选 8 个互不重复的正常混淆位置。
  3. 按表中 performer/device/room 分配录制无损 WAV；不要把同一遍演奏复制成多个设备样本。
  4. 逐条试听，在 truth JSON 填入 12 个互不重复的 measure/beat/scoreMidi/asPerformed；若出现计划外错误，也必须新增事件。
  5. 全部复核后才签署 completeErrorInventory=true，把文件放入 data/private/western-strings-round5/。
  6. 运行 npm run western:round5-targeted-intake；通过后再运行 npm run western:round5-segment-edit-path。
