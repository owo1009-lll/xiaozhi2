# M3+ 范围重定决定(2026-07-17,项目负责人拍板)

> 本决定已于 2026-07-17 并入 `western-strings-project-plan.md` 与 `western-strings-migration-plan.md` 的 M3+ 权威段落。本文继续作为范围变更记录;历史执行状态段落保留,不删改。

## 决定

**M3+ 不再要求从音频中识别技法。** 产品关键点是"非技法段 + 滑音/揉弦段的**音准与节奏**判定",不是技法分类。据此:

- **取消**:颤音/装饰音的音频检测达标要求(holdout 0% 的两类就此**作废而非待修**);粗状态分类器达标要求同步取消;
- **保留**:双音 multi-f0 支线(现 79.2%,仍按原闸门推进);fail-closed 全部纪律;学生端运行时不变。

## 新设计(三招替代技法识别)

1. **谱面标记划"不判区"(零音频检测)**:谱上的 tr、装饰小音符、泛音记号——识谱层已能读——所在音一律不硬判,输出 `insufficient_evidence`/review。**颤音在谱上,不在音频检测里。**
2. **中心音高统计判音准(技法无关)**:每个音取对齐窗内**稳定段的 f0 中位数**与谱面目标比对:平拉音=其音高;揉弦音=摆动中心;滑音=掐头去尾后的目标音。一个统计量通吃,**无需知道音在揉还是在滑**。
3. **不稳兜底守卫(fail-closed)**:音内 f0 离散度超阈 → `insufficient_evidence`,**永不指控**。这一条守卫替代全部"技法分类防误报"职能(含谱面未标的即兴揉弦/颤音)。

## 新闸门(直接考目的,不考手段)

在**既有** holdout 数据上评测(m3p 四条 + round2 + 直音负对照 + `western-strings-round2-m3plus-human-gold.json` 人工确认,**无需新录音**):

| 区域 | 要求 |
|---|---|
| 无标记平拉区 | 音准判定 precision ≥90%,unsafe=0 |
| 谱面标记区(tr/装饰/泛音) | **指控数必须=0**(全部 review/中性) |
| 揉弦/滑音区(人工 gold 确认段) | 中心音高判定 precision ≥90% |
| 节奏/起音 | 沿用 M3 core 闸门,不变 |
| 不稳兜底 | 高离散音 100% 落入 `insufficient_evidence`,0 指控 |

任一行不达标 → 该区保持 review-only;学生端开关仍走既有审批链。

## 理由(证据链)

- 技法识别只是"防冤枉"的**手段**;中位数统计 + 谱面划区 + 不稳兜底以更低复杂度达到同一目的;
- 颤音/装饰音音频检测在两轮补录后 holdout 仍 0%("无可定义正预测"),病根是 F0 可观测性与窗边界,**修复成本高且与产品目的无关**;
- 滑音(100%/75%)、揉弦(60%/75%)检测器降级为可选研究件,不再挡闸门。

## 对现有资产的处置

- m3p 四条录音与负对照:**直接复用**为新闸门的评测集(价值不变);
- 既有检测器/复核包/诊断命令:保留为研究工具,退出发布链;
- 手册合并点:替换 M3+ 节"目的/单声部音高模式/验收"三段,其余(执行状态史)原样保留。
